# Welcome to sstatic!

sstatic is a simple self-hosted URL shortener and a file server. It is a perfect companion for your personal website.

<!--@include: @/parts/wip.md-->

## Features
- URL shortener
- Static file server
- OpenID Connect authentication
- Integration with analytics providers like Plausible for tracking short URL visits
- Multi-domain support
- Built with Docker for easy deployment
- PWA-enabled
- Fully documented REST API for integration with other applications
- Open source, licensed under the MIT license
