# Security Policy

## Supported Versions

It is recommended to always use the latest version of the project.
Older versions may contain security vulnerabilities that have been fixed in newer releases.

> [!NOTE]
> Always check release notes for any breaking changes before upgrading to a new major version.

## Reporting a Vulnerability

If you have discovered a security vulnerability in this project,
please [create a Security Advisory](https://github.com/xfox111/sstatic/security/advisories/new).
**DO NOT CREATE AN ISSUE** in the public issue tracker for security vulnerabilities,
as this may expose the vulnerability to the public before it is fixed.

You can learn more about GitHub Security Advisories at
https://docs.github.com/en/code-security/security-advisories/creating-a-security-advisory.

Thank you for helping to keep this project safe!
